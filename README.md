# AstrBot钓鱼插件

一个功能齐全的钓鱼系统插件，支持钓鱼、鱼塘管理、鱼类交易等功能。

## 功能特点

- 完整的钓鱼系统，支持不同稀有度的鱼类
- 用户鱼塘管理，查看自己钓到的鱼
- 鱼类交易系统，出售鱼获得金币
- 自动钓鱼功能
- 鱼类稀有度分级系统
- 多样化的鱼类资源
- 排行榜系统（总榜/日榜/周榜/月榜）
- 天气系统，影响钓鱼成功率和费用

## 安装方法

### 通过插件市场安装

1. 在AstrBot管理面板中选择"插件市场"
2. 搜索"钓鱼"或"fishing"
3. 点击安装本插件

### 手动安装

```bash
cd {AstrBot目录}/data/plugins
git clone https://github.com/baa131/astrbot_plugin_fishing
```

## 使用方法

插件提供以下命令：

- `/钓鱼` - 开始钓鱼
- `/鱼塘` - 查看自己的鱼塘
- `/卖鱼 [鱼名] [数量]` - 卖出指定数量的鱼获得金币
- `/全部卖出` - 卖出鱼塘中所有可卖出的鱼
- `/钓鱼帮助` - 显示帮助信息
- `/自动钓鱼` - 开启/关闭自动钓鱼功能
- `/钓鱼排行` - 查看总排行榜
- `/日榜` - 查看今日排行
- `/周榜` - 查看本周排行
- `/月榜` - 查看本月排行

## 配置说明

当前版本配置在 `main.py` 的 `__init__` 中硬编码，可直接修改：

- `base_cost`: 每次钓鱼的基础成本(金币)，默认 50，实际费用受天气影响
- `auto_fishing_enabled`: 是否启用自动钓鱼功能
- `weather_update_interval`: 天气刷新间隔(秒)
- `initialize_fish_types`: 是否在启动时初始化/更新鱼类数据

数据库文件 `data/fishing.db` 会自动创建并做兼容迁移，无需手动处理。

## 常见问题

**Q: 为什么我无法开启自动钓鱼？**  
A: 请确保你有足够的金币，并且自动钓鱼功能在配置中已启用。

**Q: 如何增加稀有鱼的出现概率？**  
A: 使用特级鱼饵可以提高稀有鱼类的出现概率。
